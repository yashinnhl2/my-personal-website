## Writing a new post

Add a Markdown file to `src/content/blog/` with this frontmatter and it shows up automatically:

```md
---
title: 'My post'
description: 'One line that appears on the card.'
date: 2026-10-01
tags: ['frontend']
---
```

Set `draft: true` to keep a post out of production builds while you work on it.
